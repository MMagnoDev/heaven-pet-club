# Heaven Pet Club 🐾

Mini-site institucional para **Heaven Pet Club** — *Não é apenas um banho comum. É uma experiência.*

## 🌟 Recursos
- **Hero 50/50 Screen**: Hero elegante e imersiva com tipografia sofisticada e mascote da marca.
- **Seção de Links Rápidos**: Acesso direto ao WhatsApp, Instagram e Endereço com micro-interações.
- **Experiência Pensada para o Seu Pet**: Atendimento individualizado e banho low stress.
- **Nossos Diferenciais**: 5 pilares de cuidado e tranquilidade.
- **Banho com Ozônio**: Higienização avançada com água ozonizada.
- **Manifesto & Clube de Vantagens**: Filosofia de cuidado e fidelidade.
- **Totalmente Responsivo**: Otimizado para desktop, tablets e smartphones com tipografia fluida e prevenção de overflow horizontal.
- **Animações Fluidas**: Reveal on scroll com `IntersectionObserver` e curvas de transição suaves.

## 🛠️ Tecnologias
- HTML5 Semântico
- Vanilla CSS3 (Custom Properties, Flexbox, CSS Grid)
- JavaScript Vanilla (IntersectionObserver, Smooth Scroll)
- Google Fonts (Fraunces & Plus Jakarta Sans)

## 🚀 Como Executar Localmente
Basta abrir o arquivo `index.html` em qualquer navegador web moderno ou iniciar um servidor estático:

```bash
# Com Node.js
npx serve .
```
